# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it through GitHub private vulnerability reporting: on the
repository's **Security** tab, choose **Report a vulnerability**. Include the version or commit,
what you did, and what you expected. Expect an acknowledgement; fixes are made on `main`.

## Supported versions

Only `main`. There are no releases yet.

## Scope

This policy is about `snow-rs` itself (handling of credentials, tokens, config files, network
requests). Vulnerabilities in the official Snowflake CLI or in Snowflake itself belong to
[Snowflake](https://www.snowflake.com/en/resources/report-a-vulnerability/).
